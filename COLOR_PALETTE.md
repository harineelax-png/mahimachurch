# Project color palette

This file summarizes the colors explicitly used in the project's CSS and inline styles under `src/`. Duplicate spellings such as `#fff` and `#ffffff` are grouped together. Image colors are not included.

## Brand and warm tones

| Color | Notes |
| --- | --- |
| `#f6efe9` | Warm background used in the welcome, hero, mission, and related sections |
| `#f8eee6` | Warm light background |
| `#f1ede6` | Warm neutral background |
| `#F8EDC4` | Pale gold accent |
| `#d3c3a3`, `#d8cfa3` | Muted beige/gold accents |
| `#a67c33` | Gold-brown accent |
| `#92400e`, `#b45309`, `#c56b00` | Deep to medium warm browns/orange |
| `#e67e22`, `#f08c00`, `#f59f00` | Orange accents |
| `#ffaa00`, `#ffcc00` | Bright yellow/gold accents |
| `#fff7ed` | Very light warm background |
| `gold`, `orange`, `Yellow` | Named CSS colors used in styles |
